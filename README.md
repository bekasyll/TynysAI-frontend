# TynysAI Frontend

Веб-интерфейс для медицинской диагностической системы TynysAI. Позволяет пациентам загружать рентген-снимки и получать AI-диагностику, врачам — валидировать результаты, администраторам — управлять системой.

## Технологии

- **React 18** + **TypeScript**
- **Vite** — сборка и dev-сервер
- **Tailwind CSS** — стилизация
- **React Query v5** — серверное состояние и кэширование
- **Zustand** — клиентское состояние (авторизация)
- **React Hook Form** + **Zod** — формы и валидация
- **Axios** — HTTP-клиент
- **i18next** — интернационализация (RU, KZ, EN)
- **Lucide React** — иконки
- **date-fns** — работа с датами

## Структура проекта

```
src/
├── api/            # API-клиенты (auth, users, patients, doctors, admin)
├── assets/         # Статические ресурсы
├── components/     # UI-компоненты и layout
├── hooks/          # Кастомные хуки
├── lib/            # Утилиты
├── locales/        # Переводы (ru, kk, en)
├── pages/          # Страницы по ролям
│   ├── admin/      # Панель администратора
│   ├── auth/       # Логин и регистрация
│   ├── common/     # Общие страницы
│   ├── doctor/     # Кабинет врача
│   └── patient/    # Кабинет пациента
├── store/          # Zustand store
├── types/          # TypeScript типы
├── App.tsx         # Роутинг
└── main.tsx        # Точка входа
```

## Запуск

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера (порт 3000)
npm run dev

# Сборка для продакшена
npm run build

# Превью продакшен-сборки
npm run preview
```

## Основные функции

**Пациент:**
- Загрузка рентген-снимков и получение AI-диагностики
- Просмотр лабораторных результатов и диагностических отчётов
- Управление профилем и уведомления

**Врач:**
- Валидация AI-результатов диагностики
- Создание диагностических отчётов и лабораторных результатов
- Управление пациентами

**Администратор:**
- Управление пользователями
- Одобрение регистрации врачей
- Дашборд системной статистики

## Бэкенд

Фронтенд подключается к Spring Boot API через Vite proxy (`localhost:8080/api`).
